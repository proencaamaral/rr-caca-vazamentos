# 🚰 Site de Serviços - RR Caça Vazamentos

Landing page profissional desenvolvida para a **RR Caça Vazamentos**, focada na captação e conversão rápida de clientes locais via atendimento por WhatsApp e redes sociais.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído para ser leve, de carregamento rápido e total responsividade (otimizado para dispositivos móveis):

*   **HTML5** (Estrutura semântica)
*   **CSS3** (Estilização moderna e layout responsivo)
*   **JavaScript** (Interatividade e dinamismo)
*   **Hospedagem:** [Vercel](https://rr-caca-vazamentos.vercel.app/)

---

## ✨ Principais Funcionalidades

*   **Botão Flutuante de Contato:** Ícones fixos na tela facilitando o contato imediato via **WhatsApp** e direcionamento direto para o **Instagram**.
*   **Apresentação de Serviços:** Exibição clara dos serviços de detecção de vazamentos e suporte hidráulico.
*   **Design Responsivo:** Adaptado para navegação fluida em celulares, tablets e desktops.
